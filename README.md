# 🎮 Dev City | Seleção Interativa de Personagens

## 📌 Sobre o Projeto

O **Dev City** é um projeto de desenvolvimento web front-end inspirado na estética e no universo da franquia Grand Theft Auto (GTA).

O objetivo é criar uma interface visualmente atrativa e interativa, permitindo que o usuário selecione diferentes personagens e personalize elementos visuais da página por meio de botões.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript**, aplicando conceitos fundamentais de desenvolvimento web, lógica de programação, manipulação do DOM, funções, eventos e estilização dinâmica.

Além de proporcionar uma experiência visual inspirada em jogos, o Dev City representa uma aplicação prática dos conhecimentos adquiridos durante os estudos de desenvolvimento front-end.

## 🚀 Funcionalidades

### 🎭 Seleção de Personagens
O usuário pode escolher entre três personagens:

- **Lucia:** representada pela cor rosa.
- **Jason:** representado pela cor azul.
- **CJ:** representado pela cor verde.

Ao selecionar um personagem, o JavaScript executa automaticamente três alterações na interface:

1. Atualiza o nome do personagem exibido na página.
2. Substitui a imagem principal pelo personagem selecionado.
3. Altera dinamicamente a cor do nome de acordo com o personagem.

### 🖼️ Alternância de Imagens de Fundo
O projeto também possui um botão interativo que permite alternar entre duas imagens de fundo.

A funcionalidade utiliza uma variável booleana (`true` ou `false`) e uma estrutura condicional `if/else` para identificar o estado atual do fundo e realizar a alteração.

O usuário pode alternar entre as imagens quantas vezes desejar, sem precisar atualizar a página.

### 🎨 Interface Visual
A interface foi desenvolvida com foco em uma identidade visual inspirada em jogos, utilizando:

- Imagens de personagens em destaque.
- Tipografia personalizada com Google Fonts.
- Botões circulares para seleção de personagens.
- Posicionamento de elementos com CSS.
- Flexbox para organização do menu.
- Imagens de fundo ajustadas com `background-size: cover`.
- Cores personalizadas para cada personagem.

## 🛠️ Tecnologias Utilizadas

**HTML5**
- Estruturação dos elementos da página.
- Organização de textos, imagens e botões.
- Utilização de eventos `onclick`.

**CSS3**
- Estilização da interface.
- Posicionamento de elementos.
- Flexbox.
- Personalização de cores, fontes e imagens.
- Utilização de unidades relativas como `vh` e `vw`.

**JavaScript**
- Declaração de variáveis com `let`.
- Criação de funções com parâmetros.
- Manipulação do DOM com `document.querySelector()`.
- Alteração de conteúdos e atributos HTML.
- Modificação dinâmica de propriedades CSS.
- Estruturas condicionais `if/else`.
- Controle de estado com variáveis booleanas.
- Manipulação de eventos de clique.

## 🧠 Conceitos Praticados

Durante o desenvolvimento, foram aplicados conhecimentos de lógica de programação e algoritmos para organizar o funcionamento das funcionalidades.

O projeto demonstra como HTML, CSS e JavaScript trabalham juntos:

- O HTML define a estrutura.
- O CSS controla a aparência.
- O JavaScript adiciona interatividade e comportamento dinâmico.

Também foram praticados conceitos de passagem de parâmetros, seleção de elementos HTML e atualização de informações na página sem necessidade de recarregamento.
